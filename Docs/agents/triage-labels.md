# 分诊标签（Triage Labels）

技能使用五个标准分诊角色。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | Label in our tracker（本仓库标签） | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 需要维护者评估 |
| `needs-info`               | `needs-info`         | 等待提出者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整描述，可交给无人值守的 agent |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不处理 |

技能提到某个角色时（例如“打上可交给 agent 的分诊标签”），使用上表中对应的本仓库标签字符串。

如需改用其他标签名，修改 “Label in our tracker” 一列即可。
